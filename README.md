
# 🎮 Trivia Game project 

This trivia game is made out of three parts 
- A Backend made with CPP and SQLite which is incharge on keeping the questions and rooms and sending data to the frontned
- A proxy written in python which connects between the cpp and the fronend. while the backend is communicating with a socket connection the fronend communicates with flask requests 
- A React  frontent responsible for showing the GUI of the game




## Features

- Rooms
- User stats
- Head to Head
- Web Game
